**Mirage** - это экспериментальный интерфейс для извлечения текста из изображений. Проект разрушает привычные шаблоны веб-дизайна, предлагая асимметричную композицию и контрастную цветовую палитру.

Утилита использует движок EasyOCR для распознавания кириллицы и латиницы.

## Особенности

- Загрузка форматов JPG, PNG, JPEG.
- Поддержка русского и английского языков.
- Асимметричный интерфейс с визуальными акцентами.
- Автоматическое сохранение текста в файл.

## Требования

- Python 3.9+
- pip

## Установка

**1. Клонирование проекта:**
```bash
git clone <URL_репозитория>

cd <папка_проекта>
```
**2. Настройка окружения:**

# Для ОС Windows
python -m venv .venv
.venv\Scripts\activate

# Для UNIX-систем
python3 -m venv .venv
source .venv/bin/activate

**3. Загрузка зависимостей:**

pip install --upgrade pip
pip install -r requirements.txt

**4. Запуск программы:**

streamlit run app.py

## Использование

1. Загрузите изображение в интерфейс.
2. Нажмите кнопку "Распознать".
3. Текст будет автоматически сохранен в файл.
